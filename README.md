# Automated Visitor Counter

An Arduino-based automated visitor counting system that detects people entering and leaving a room using IR sensors and maintains the current visitor count.

## Features

- Automatic visitor detection
- Separate entry and exit detection
- Real-time visitor count
- Arduino-based control
- IR sensor integration
- Automatic increment and decrement of visitor count

## Hardware Components

- Arduino Uno R3
- IR Sensors
- LCD Display
- Breadboard
- Jumper Wires
- Power Supply

## Technologies & Tools

- Arduino Uno
- Arduino IDE
- Embedded C / Arduino C
- IR Sensor Integration
- Digital Electronics

## Working Principle

1. The IR sensors detect a person passing through the entrance.
2. The sensor sequence determines whether the person is entering or leaving.
3. When a person enters, the visitor count increases by one.
4. When a person exits, the visitor count decreases by one.
5. The current number of visitors is displayed on the LCD.

## System Flow

Person Detection → IR Sensors → Arduino → Visitor Count Processing → LCD Display
